How it is hosted

This page loads the upstream planner template, stylesheet, script, and schedule CSV files directly from the website repository's train-trip-planner submodule checkout. A small local bridge adapts the Flask API calls to browser-side static hosting.

Hosted adaptation

  • Source tracking Updating the submodule updates the planner assets this page consumes, so the hosted version can intentionally move forward with upstream commits.
  • Static-site bridge The bridge keeps browser save/load behavior and route generation working without the original Flask backend.
  • Schedule source Route data is read from the upstream repository's schedule CSV files instead of a duplicated website-only JSON copy.
