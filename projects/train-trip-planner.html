Launch the hosted tool View the source project

Plan a route

Search the included Amtrak sample routes, add optional stopovers, and generate a dated itinerary in the browser.

Hosted adaptation

  • Source tracking The website repository now includes the upstream planner project as a git submodule, so future upstream updates can be pulled in deliberately before refreshing this hosted static version.
  • What is included Direct trips, the Chicago connection, stopovers, CSV export, and browser-saved itineraries.
  • How schedules are saved Saved plans stay in this browser using local storage instead of the original Flask file-based save flow.
  • Route data source The planner ships with schedule data from the original project so it can run on a static host.
